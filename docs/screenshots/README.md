## 补充步骤 / Adding screenshots

1. 使用专用测试数据，移除姓名、当前位置、家庭/工作地址、通知、电话、设备标识、SSID、IP/MAC、认证目录及密钥。不要直接复制 `.local/`、运行日志或现有私人真机截图。
2. 截图应来自真实程序，注明版本、操作系统和连接模式；不得把设计图或未验证的平台当成运行结果。只保留公开展示所需的 UI 区域。
3. 保存 PNG/WebP，保持文字可读并适当压缩。检查地图、媒体封面等第三方内容是否适合公开分发；优先使用不含个人或第三方敏感内容的测试画面。
4. 在两个 README 中同时替换占位图片链接，添加准确的中英说明。截图不替代协议、声音或稳定性验收记录。

1. Use dedicated test data. Remove names, location, home/work addresses, notifications, phone details, device identifiers, SSIDs, IP/MAC addresses, identity paths and keys. Do not copy `.local/`, runtime logs or existing private device screenshots into the repository.
