# v0.1.4 桌面预览版 / Desktop preview

本版本汇总 v0.1.2–v0.1.4 本地修复，并加入用户提供的 Windows 实际截图。提供 Windows 安装包、Linux x64／ARM64 DEB 与 macOS 双架构预览包，附便携包、对应源码和 SHA256SUMS。Android 与其他移动端本轮不构建。

## 下载与验证 / Download and verify

- Windows 11 x64：`RustCarPlay-0.1.4-windows-x86_64-setup.exe`。
- Ubuntu 24.04 x64：`rustcarplay_0.1.4_amd64.deb`，安装命令 `sudo apt install ./rustcarplay_0.1.4_amd64.deb`。
- Ubuntu 24.04 ARM64：`rustcarplay_0.1.4_arm64.deb`。
- macOS：`RustCarPlay-0.1.4-macos-aarch64.dmg` 或 `RustCarPlay-0.1.4-macos-x86_64.dmg`。仅界面与核心预览，原生连接后端未完成。

下载后对照同一 Release 的 `SHA256SUMS`。Linux 仍待真机验证；虚拟机测试需要正确的设备直通，不能由安装成功推断 CarPlay 可用。

## 本轮变化 / Changes

- Windows USB：准备入口、共享恢复记录、签名验证工具、PowerShell 5.1／7 兼容、实际阶段显示与跨进程重启续接；Windows 拒绝软件重启时仍需物理拔插。
- 媒体：HEVC 协商声明与配置块长度修复；移除逐帧额外像素转换，复用 GPU 纹理并按新帧通知刷新。未完成硬件解码或端到端性能对照测试。
- 连接：蓝牙取消／超时清理、会话端口回收、音频建流诊断与无线交接处理。
- 界面：车辆应用占位、常见分辨率预设、默认 60 fps（保留旧设置）。
- 文档：中英文 README 加入两张 Windows 截图并更新 USB 操作说明。

本地验证包括工作区测试、原生合成音视频、桌面回归、Clippy、便携包及安装／卸载检查。2026-10-09，同一台 iPhone 拔插后成功继续 USB 准备，独立读取确认配置从 3 切至 6；这项验证不代替视频、声音和长期稳定性验收。此前用户已确认 Windows 有线／无线画面、触控和声音，其他平台仍按 README 标记。

This preview consolidates the local v0.1.2–v0.1.4 fixes and adds actual Windows screenshots. It improves USB preparation and restart recovery, HEVC negotiation/config extraction, media copies and texture reuse, connection teardown, and desktop configuration. Assets include desktop installers, portable archives, corresponding source and checksums. Windows has limited physical-device validation; Linux remains unverified with a phone, and macOS is a GUI/core preview without connection support. No hardware decoding or measured speedup is claimed. Mobile platforms are not built.
