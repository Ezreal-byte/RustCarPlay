# v0.1.4 开发更新 / Development update

本次提交汇总 v0.1.2–v0.1.4 本地修复，并加入用户提供的 Windows 实际截图。此文档不表示已经发布 v0.1.4 Release；公开安装包以 Releases 页面为准。

- Windows USB：准备入口、共享恢复记录、签名验证工具、PowerShell 5.1／7 兼容、实际阶段显示与跨进程重启续接；Windows 拒绝软件重启时仍需物理拔插。
- 媒体：HEVC 协商声明与配置块长度修复；移除逐帧额外像素转换，复用 GPU 纹理并按新帧通知刷新。未完成硬件解码或端到端性能对照测试。
- 连接：蓝牙取消／超时清理、会话端口回收、音频建流诊断与无线交接处理。
- 界面：车辆应用占位、常见分辨率预设、默认 60 fps（保留旧设置）。
- 文档：中英文 README 加入两张 Windows 截图并更新 USB 操作说明。

本地验证包括工作区测试、原生合成音视频、桌面回归、Clippy、便携包及安装／卸载检查。2026-10-09，同一台 iPhone 拔插后成功继续 USB 准备，独立读取确认配置从 3 切至 6；这项验证不代替视频、声音和长期稳定性验收。此前用户已确认 Windows 有线／无线画面、触控和声音，其他平台仍按 README 标记。

This commit consolidates the local v0.1.2–v0.1.4 fixes and adds actual Windows screenshots. It improves USB preparation and restart recovery, HEVC negotiation/config extraction, media copies and texture reuse, connection teardown, and desktop configuration. It does not announce a published v0.1.4 release or claim hardware decoding, measured speedups, or device validation on Linux/macOS.
