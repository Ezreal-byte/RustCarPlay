# 0.1.2 本地 Windows 测试版 / Local Windows test build

此构建只用于本地验证，没有发布 GitHub Release 或运行 GitHub CI。安装时保留已有设置、配对与 USB 恢复记录；已保存的帧率不被覆盖，新配置默认为 60 fps。

This is a local Windows test build, not a GitHub release. Existing settings, pairings and USB rollback records are retained. New settings default to 60 fps; saved frame rates are respected.

本轮调整 / Changes:

- USB 页面提供 Windows 准备入口，提升权限后运行设备配置流程，按需要提示拔插；恢复记录移到固定用户数据目录。
- HEVC 的 `/info` 和 SETUP 能力声明保持一致；无线 iAP 通道与蓝牙交接协商补齐。
- 蓝牙连接超时和取消时显式关闭正在建立的连接，允许重试；接收端停止后释放监听和事件通道。
- 添加车辆应用占位入口、分辨率预设和默认 60 fps。
- 解码帧直接上传到复用的 GPU 纹理，移除每帧额外的 egui 像素转换和分配；新帧通知 UI 刷新。仍保留软件解码，未声称零复制或硬件解码。

回归重点 / Device checks:

1. USB：解锁手机，选择 USB iPhone；如仍提示驱动配置，点击“准备 Windows USB”并根据提示拔插，再连接。
2. 局域网：播放音乐、暂停、继续，确认声音来自电脑；断开后再次连接。
3. HEVC：断开后启用，再连接并检查画面与声音；异常时保留日志，H.264 可用于对照。
4. 重连：连接中取消、手机断开、重复连接，确认不再需要重启软件释放端口。
5. 性能：以相同分辨率、帧率、画面内容比较 CPU/内存；此次移除了额外帧拷贝，但不能由单元测试推断整机占用降幅。

Hardware regression results must be recorded separately. Compilation, synthetic codec checks and installer smoke tests do not establish iPhone, Bluetooth driver or HEVC compatibility on another machine.
