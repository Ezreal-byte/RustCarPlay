# 0.1.4 本地 Windows USB 修复 / Local Windows USB fix

仅生成本地测试安装包，不触发 GitHub CI 或发布。

Local installer only; no GitHub CI or release.

- 准备界面显示检查环境、驱动校验、设备重启、描述符读取、配置激活和清理等实际阶段。Windows 自动批准提权时不会有 UAC 弹窗，界面不再一直要求处理弹窗。
- 等待物理拔插的进度保存到共享用户数据目录。重启软件后可继续同一台手机的准备；仍会重新核对设备身份和初始 USB 模式。兼容恢复 0.1.3 留下的同设备、30 分钟内的描述符记录。
- 准备完成或无法确认安全清理时清除续接记录。普通连接仍要求正确配置已激活。
- PowerShell 版本检测增加超时；正在修改驱动配置的进程不会因界面等待超时被强制终止。

The UI reports actual preparation stages, preserves same-device replug checkpoints across restarts, and recognizes fresh 0.1.3 descriptor checkpoints. Administrator elevation may be approved silently by Windows policy. Resume still validates the phone and its initial mode; it never assumes a fixed USB configuration. Shell version detection is bounded; driver transactions are not forcibly terminated.

USB 软件重启若返回 3010，仍需要按提示物理拔插数据线。保存进度和显示阶段不能替代 Windows 要求的设备重枚举。

A physical replug remains necessary when Windows refuses the software restart (3010). UI progress is not evidence of successful device activation; success requires reading back the active CarPlay configuration.
