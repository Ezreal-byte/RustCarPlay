# RustCarPlay 0.1.0

[中文](#中文) · [English](#english)

## 中文

首个公开开发版本。基于 DiPlay 的 Rust CarPlay 接收端，使用共享协议核心、平台适配层、egui/wgpu 桌面界面和 GStreamer 媒体后端。

- 提供局域网、电脑热点和 USB 三种连接入口；局域网使用当前系统 Wi-Fi 配置，不要求在软件中重复输入密码。
- 已实现 iAP2、USBMUX/Lockdown/CarKit、AirPlay 配对与媒体传输、视频解码、音频播放和触控。
- Windows 当前测试设备已验证无线/USB 画面、点击返回、声音，以及 USB 暂停继续和软件断开重连。
- 发布 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 构建。Linux 尚未真机验证；macOS 为界面/核心构建预览，原生连接适配未完成。
- Android 和 HarmonyOS 原生应用尚未交付，后续开发路线见 [移动端移植说明](https://github.com/Ezreal-byte/RustCarPlay/blob/v0.1.0/docs/MOBILE_PORTING.md)。

**运行条件：**二进制压缩包不包含 GStreamer、Apple 服务、USB 驱动或认证身份。请按包内说明安装运行时，并自行配置有效的配件认证后端。Windows USB 需要单独准备所选设备的驱动/复合配置；目前尚非即插即用。

`source.tar.gz` 提供项目及锁定的 Rust 依赖源码、许可证和离线 Cargo 配置；`SHA256SUMS` 用于校验附件。GStreamer 等原生运行时由用户另外安装，不在本次二进制中捆绑。

这是开发预览，尚未完成 20 次连接循环、两小时媒体运行、Siri/通话、AEC、所有异常恢复、第二屏及车辆集成验收。构建成功不代表上述平台均能连接 iPhone，也不表示 Apple 认证。

## English

The first public development release of a Rust CarPlay receiver based on DiPlay. It combines a shared protocol core, native platform adapters, an egui/wgpu desktop interface, and GStreamer playback.

- LAN, computer-hotspot, and USB connection modes. LAN uses the current system Wi-Fi profile without asking users to re-enter its password in the app.
- iAP2, USBMUX/Lockdown/CarKit, AirPlay pairing and media transport, video decoding, audio playback, and touch input.
- Wireless/USB video, touch/back navigation, and audio have been tested on the current Windows/iPhone setup, including USB pause/resume and software reconnect.
- Builds for Windows x64, Linux x64/ARM64, and macOS Intel/Apple Silicon. Linux has no physical-device validation yet. macOS is a UI/core build preview; native connection adapters remain incomplete.
- Android and HarmonyOS applications are not included. See the [mobile porting guide](https://github.com/Ezreal-byte/RustCarPlay/blob/v0.1.0/docs/MOBILE_PORTING.md) for continuing development.

**Requirements:** binary archives do not include GStreamer, Apple services, USB drivers, or an accessory authentication identity. Install the documented runtime and configure a valid authentication backend separately. Windows USB requires explicit preparation of the selected device's composite configuration and drivers; it is not yet plug-and-play.

The `source.tar.gz` asset includes project source, locked Rust dependency sources and licenses, and offline Cargo configuration. Use `SHA256SUMS` to verify the assets. Native runtimes such as GStreamer are installed separately and are not bundled.

This development preview has not completed the 20-cycle, two-hour media, Siri/call, AEC, recovery, second-screen, or vehicle-integration acceptance checks. Successful compilation does not establish iPhone interoperability on every platform or imply Apple certification.
