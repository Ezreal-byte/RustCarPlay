# RustCarPlay 0.1.5 桌面预览版 / Desktop preview

汇总 v0.1.2–v0.1.4 的 USB、媒体与桌面修复，并修复 Windows CI 解压 MSYS2 USB 依赖失败的问题。v0.1.4 发布构建未完成，没有公开安装包；本次以 v0.1.5 发布，保留原标签记录。

## 下载

- Windows 11 x64：`RustCarPlay-0.1.5-windows-x86_64-setup.exe`。
- Ubuntu 24.04 x64：`rustcarplay_0.1.5_amd64.deb`。
- Ubuntu 24.04 ARM64：`rustcarplay_0.1.5_arm64.deb`。
- macOS：`RustCarPlay-0.1.5-macos-aarch64.dmg` 或 `RustCarPlay-0.1.5-macos-x86_64.dmg`；仅界面与核心预览，原生连接后端未完成。

另附五个平台的便携包、项目及原生依赖对应源码，以及 `SHA256SUMS`。Android 与其他移动端本轮不构建。

Ubuntu 安装示例：

```sh
sudo apt install ./rustcarplay_0.1.5_amd64.deb
```

## 修复与改进

- Windows USB：驱动准备入口、签名验证、共享恢复记录、PowerShell 5.1／7 兼容、实际阶段显示和拔插续接进度保存。系统可能自动批准管理员权限；软件重启设备失败时仍需物理拔插。
- 媒体与连接：HEVC 协商与配置块边界修复、蓝牙取消／超时清理、会话端口回收、音频建流和无线交接处理。
- 显示：减少额外像素转换并复用 GPU 纹理；按新帧刷新。默认 60 fps、常用分辨率预设及车辆应用占位入口。
- 打包：CI 用固定 `zstandard==0.25.0` 解包经过 SHA256 校验的 USB 依赖，避免依赖 runner 的 tar 子进程；校验路径、链接、重复条目和截断数据。
- 文档：中英文 README 加入两张 Windows 实际截图。

## 验证边界

Windows 已有一台 iPhone 的无线／USB 画面、触控和声音初测；2026-10-09 另验证 USB 准备续接成功，独立读取配置值为 6。Linux x64／ARM64 有实现和构建检查，仍待真机验收；macOS 不能完成接收端连接。HEVC 真机回归、Siri／通话、两小时运行和更多设备仍待验收。不宣称硬件解码、实测性能提升或通用车机兼容。

## English

This desktop preview consolidates the USB, media, connection and UI fixes from local v0.1.2–v0.1.4 builds. It fixes a Windows release-builder failure when extracting MSYS2 USB packages by using a pinned Python/Zstandard decoder with hash and archive validation. The unsuccessful v0.1.4 tag is retained; v0.1.5 is the release version.

Includes Windows Setup, Linux x64/ARM64 DEB, macOS Intel/Apple Silicon DMG previews, portable archives, corresponding source and checksums. Windows has limited physical iPhone validation; Linux awaits device acceptance; macOS is GUI/core only without native connection support. Mobile platforms are not built. No hardware decoding, measured speedup or universal compatibility is claimed.
