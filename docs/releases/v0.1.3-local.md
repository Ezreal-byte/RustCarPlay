# 0.1.3 本地 Windows 测试版 / Local Windows test build

仅本地打包，不推送代码、不运行 GitHub CI、不创建 Release。

Local installer only; no GitHub CI or release is triggered.

## 修复 / Fixes

- HEVC：日志显示握手和视频流建立成功，随后在 `hvcC` 配置解析时断开。提取配置现在遵守 ISO-BMFF 配置块声明的长度，避免把后续元数据传给解码器；仍拒绝截断、越界和配置块内部的多余数据。日志只记录编码类型及数据长度，便于真机复测。
- USB：Windows 要求拔插时，界面持续显示中文步骤并禁用连接按钮；未激活正确 USB 配置的设备必须先完成“准备 Windows USB”。防止在等待拔插期间再次连接，将手机切入无法续接准备的状态。

- HEVC codec extraction respects the declared configuration-box length, excluding adjacent metadata while retaining strict bounds checks. Diagnostics record only codec and lengths.
- Windows USB connections are gated on preparation and active interfaces. A pending physical replug is shown explicitly and blocks an ordinary connection attempt.

## 验证 / Validation

覆盖原始配置、带后续元数据的配置块、扩展长度与非法长度；原生 GStreamer H.264/H.265 编解码回归通过同一提取入口。USB 界面测试覆盖配置未激活、等待拔插、准备完成与切回局域网。

Regression coverage includes raw records, adjacent metadata, extended and invalid sizes, native H.264/H.265 decoding, and USB preparation gating.

实际 iPhone HEVC 连接仍需复测。USB 如提示拔插，请拔下数据线至少 5 秒，重新插入并解锁，再点击“已重新插好，继续准备 USB”；收到“准备完成”后连接。软件测试不替代真机验证。

Physical iPhone HEVC and USB retests remain required. When requested, unplug for at least five seconds, reconnect and unlock, then resume USB preparation before connecting.
